# Gled has moved to [github.com/gled-project](https://github.com/gled-project)

The current Gled is [gled-project/gled](https://github.com/gled-project/gled),
with [gled-hep](https://github.com/gled-project/gled-hep),
[gled-builder](https://github.com/gled-project/gled-builder),
[gled-attic](https://github.com/gled-project/gled-attic),
[gled-papers](https://github.com/gled-project/gled-papers) and
[greed](https://github.com/gled-project/greed).

This repository is an archived import of the Gled svn trunk with its history,
up to revision 2975 (March 2015). The svn repository, read-only since October
2026, holds the history up to revision 3045, where the gled-project
repositories start.
